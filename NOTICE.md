# Third-Party Notices

## Impeccable

Airtight's structure is derived from Paul Bakaus's Impeccable: the source-first
build with generated per-harness output, the registry/matcher split, the
two-tier edit hook, the suppression ladder and its agent-authority boundary, the
`PRODUCT.md`/`DESIGN.md` context pairing that became `THREATS.md`/`CONTROLS.md`,
and the convention that a rule ships with both a true-positive and a
false-positive corpus.

No Impeccable source is vendored. What is reused is design, conventions, and
file layout, reimplemented for security.

**Original work:** https://github.com/pbakaus/impeccable

**Author:** Paul Bakaus

Impeccable itself began from Anthropic's `frontend-design` skill
(https://github.com/anthropics/skills), and this project continues that lineage.
